# AMUNTCHI Android V5

Application Android de la Mini Quincaillerie AMUNTCHI, synchronisée avec le logiciel PC via Supabase.

- `www/` : l'application (HTML/JS, fonctionne hors ligne, données dans le téléphone)
- `.github/workflows/build-apk.yml` : fabrication automatique de l'APK à chaque envoi (onglet **Actions**, puis **Releases**)
- `build/` : icônes, clé de signature fixe (mises à jour sans perte de données), script de personnalisation

Voir le guide d'installation fourni avec le logiciel.
